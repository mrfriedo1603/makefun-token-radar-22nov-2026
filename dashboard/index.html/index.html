How the number is made

A protocol is listed as “records no token” when the snapshot records no market cap, CoinGecko id or symbol for it — that is the snapshot's record, never a promise that no token exists or that one will be issued. Implied value is this board's own claim, not a price and not investment advice. Snapshot source and date are shown above; the board never calls a live API.
